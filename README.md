# 语脉新生

> 一句网络古风文案，到底有没有出处？查一下就知道。

网上到处流传的「无人与我立黄昏，无人问我粥可温」「山河远阔，人间烟火」，
常被标成李白、沈复、林徽因写的 —— 大多数其实一个字的原文都找不到。

**语脉新生**就是用来查这件事的：粘贴一句话，它逐句告诉你哪些有真实出处（到篇名）、
哪些是现代人写的、哪些是把原句改了字。顺手也帮你把大白话改成规范的古风表达，
并能查到 60 部经典里可用的名句。

## 溯源核验：查一句古风文案的底细

<img src="https://cdn.jsdelivr.net/gh/pi-coding/yumai-xinsheng@main/preview/verify.png" alt="溯源核验">

**怎么用**：把整段文案粘进输入框（可以好几句话一起），点「开始核验」。

**会得到什么**：

1. **逐句结论** —— 每一句单独判定，绿的能引用，黄的要注意，红的别当古人写的。
2. **三段依据** ——
   - **实际情况**：这句到底是什么，错在哪
   - **修改建议**：想用的话该怎么写、怎么标注
   - **核验方式**：判断依据是什么（全文核对 / 篇名比对 / 语料检索）
3. **总体结论** —— 一段话里真假混着写时，会直接告诉你「真伪混杂，建议分开处理」。

### 六种结论分别是什么意思

| 结论 | 什么意思 | 你该怎么做 |
|---|---|---|
| **有据可考** | 真的有出处，能给到篇名 | 放心引用，记得标出处 |
| **出处讹变** | 有原句，但字词被改了 | 用回原文，或注明是化用 |
| **出处存疑** | 出处归属说不准，常见于张冠李戴 | 别轻易标注作者，先查证 |
| **伪古风** | 查无此句，是现代拟古创作 | 别标古人，写「网络流行拟古句」 |
| **真伪混杂** | 真句和伪句拼在一起 | 真句标出处，伪句注「当代创作」 |
| **未收录** | 库里没这条，**不代表是假的** | 补上出处再使用更稳妥 |

> 「未收录」是六种里最容易被误解的一种 —— 它只说明我们的语料里没检索到，
> 可能是生僻典故，也可能是你自己的原创。它**不是**「伪古风」的意思。

## 古籍书库：找一句合适的古诗词

<img src="https://cdn.jsdelivr.net/gh/pi-coding/yumai-xinsheng@main/preview/books.png" alt="古籍书库">

60 部经典，按**经 · 史 · 子 · 集**四部分类。

- **能搜**：书名、作者、篇名、常见别名都行（搜「老子」能出《道德经》）
- **每部书给什么**：一段要旨（这本书讲什么、为什么值得读）+ 几句**带篇名的**名句 + 相关语料
- **关联分三种，不会混着说**：直接引用 / 同部类参考 / 同作者作品

> 我们只提供**书目信息和名句摘录**，不含 60 部书的正文 —— 名句取自通行本，
> 供你核对用，不能替代原文校勘。

## 语言改编工坊：把大白话改成规范的古风

<img src="https://cdn.jsdelivr.net/gh/pi-coding/yumai-xinsheng@main/preview/workshop.png" alt="语言改编工坊">

**怎么用**：左边选三个东西 —— **语境**（日常 / 职场 / 学习 / 情感 / 社交）、
**语气**（自然 / 俏皮 / 庄重 / 深情 / 豪迈 / 温婉）、**语法形式**；右边输入白话，点改编。

**跟直接让 AI 写不一样的地方**：它会把**用了哪条规则、出自哪本书**一并摊开给你看，
不是给你一段没法查证的「古风腔」。

改完的作品可以收藏、复制；登录后改编历史会同步到「我的」。

## 还有一些顺手的功能

<img src="https://cdn.jsdelivr.net/gh/pi-coding/yumai-xinsheng@main/preview/calendar.png" alt="每日一词 · 科普日历">

- **数据看板**：语料分类分布、核验结论计数、热门检索

## 关于数据，有三件事想先说清楚

1. **语料分两档，界面上会标出来。** 真正出自调研的只有 118 条，其余 1896 条是按模板扩充的。
   默认只显示真实的那部分 —— 模板语料不会被当作调研样本给你看。
2. **「可信度 82」不是学术指标。** 它是本工具给的一个参考分，按命中类型的严重程度折算，
   未收录时不给分。**不要**把它当成调研数据引用。
3. **古籍只给要旨和名句，不给全文。** 因为我们手上的语料里就没有全文，
   与其拼一个来路不明的电子版，不如老实说明。

## 常见问题

**Q：我查的诗被判「未收录」，是不是被当成假的了？**
不是。未收录只表示我们的语料里没检索到。生僻典故、地方志里的句子、你自己的原创，都会落到这一档。

**Q：为什么只有 60 部书？**
这是调研语料的覆盖范围。我们把范围收窄，是为了每一条都能人工核对过 —— 宁可少，不要错。

**Q：断网了还能用吗？**
小程序可以（内置了同一份数据，会标「离线」）；网页版需要后端在跑。

**Q：我输入的内容会被保存吗？**
不登录时只做匿名计数，不会给你留下任何可查的记录。登录后核验记录会存到「我的」里，方便回看。

**Q：能商用或者转载吗？**
仓库暂未声明开源许可证，默认保留所有权利。想用请开 Issue 说明用途。
